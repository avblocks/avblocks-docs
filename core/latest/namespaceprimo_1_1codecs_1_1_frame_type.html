Detailed Description

Defines frame types for audio codecs, particularly for G.711 encoding.

These types indicate the nature of the encoded frame, such as voice activity, silence, or errors, and are used to optimize transmission and decoding. Values are based on ITU-T G.711 standards and related codecs like G.729 Annex B for VAD.

enum Enum

Enumeration of frame types used in audio encoding/decoding.

Negative values indicate errors or unspecified states, while positive values represent specific frame categories.

Enumerator
None 

Unknown frame type or frame type is not specified.

Used when the frame type cannot be determined or is undefined.

G711BadFrame 

G.711 bad frame: Indicates a corrupted or invalid frame that cannot be decoded.

This may occur due to transmission errors or data loss.

G711UntransmittedFrame 

G.711 untransmitted frame: Represents a frame that was not transmitted, often due to silence or inactivity in VAD-enabled modes.

Equivalent to no data sent, saving bandwidth.

G711SIDFrame 

G.711 SID (Silence Insertion Descriptor) frame: A compact frame describing silence.

Contains parameters (e.g., from G.729 Annex B VAD) to reconstruct background noise, used when voice activity is low to reduce bitrate.

G711VoiceFrame 

G.711 voice frame: A full voice/active frame encoded in G.711 A-law or μ-law.

Contains compressed PCM data for speech or active audio segments. Frame size is 80 bytes (10ms at at sampling rate 8kHz, 8 bits per sample).

G726VoiceFrame 

G.726 voice frame: A full voice/active frame encoded in G.726 Adaptive Differential Pulse Code Modulation (ADPCM).

This is the only supported frame type for G.726 codec. Frame size varies based on the bitrate: 20, 30, 40 or 50 bytes for 16, 24, 32 or 40 kbps respectively (10ms at sampling rate 8kHz, 2, 3, 4, 5 bits per sample). Voice Activity Detection (VAD) and Packet Loss Concealment (PLC) are not supported for G.726.
