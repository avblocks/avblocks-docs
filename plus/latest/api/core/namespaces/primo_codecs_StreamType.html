primo::codecs::StreamType¶

Defines major audio and video stream types, and file formats (a.k.a.

enum primo::codecs::StreamType::Enum¶

StreamType::Enum.

Values:

enumerator Unknown¶

The stream type is not defined or is unknown.

enumerator BEGIN_AUDIO¶

This constant marks the start of audio elementary streams.

It is not a valid stream type on its own.

enumerator LPCM¶

Audio encoded using pulse code modulation (PCM) with linear quantization.

enumerator ALAW_PCM¶

G.711 A-law PCM.

enumerator MULAW_PCM¶

G.711 Mu-law PCM.

enumerator VIDEO_DVD_PCM¶

LPCM with specific sample packing for Video-DVD.

enumerator AC3¶

Dolby Digital Audio (a.k.a.

AC-3). AC-3 is defined in ATSC A/52-A and A/52-B.

enumerator DTS¶

DTS (Digital Theater Systems) Coherent Acoustics codec, transportable through S/PDIF and used on DVDs, CD-DAs, LDs, and in wave files.

enumerator MPEG_Audio¶

MPEG-1 or MPEG-2 Audio, Layer I, II and III.

enumerator Vorbis¶

Vorbis Audio Codec.

This is an open standard audio codec developed by the Xiph.Org Foundation.

enumerator AAC¶

Advanced Audio Coding.

Initially it was defined in Part 7 of the MPEG-2 standard (known formally as ISO/IEC 13818-7) which is now obsolete.

Currently it is defined in Part 3 of the MPEG-4 standard (known formally as ISO/IEC 14496-3).

enumerator AMRNB¶

Adaptive Multi-Rate audio (Narrow Band).

enumerator AMRWB¶

Adaptive Multi-Rate audio (Wide Band).

enumerator G726_ADPCM¶

G.726 ITU-T ADPCM.

enumerator WMA¶

Microsoft Windows Media Audio.

enumerator WMA_Professional¶

Microsoft Windows Media Audio Professional.

enumerator WMA_Lossless¶

Microsoft Windows Media Audio Lossless.

enumerator Opus¶

Opus Audio Codec.

This is an open, royalty-free audio codec developed by the Xiph.Org Foundation and standardized by IETF.

enumerator END_AUDIO¶

This constant marks the end of audio elementary streams.

It is not a valid stream type on its own.

enumerator BEGIN_VIDEO¶

This constant marks the start of video elementary streams.

It is not a valid stream type on its own.

enumerator UncompressedVideo¶

Uncompressed video stream.

enumerator MPEG1_Video¶

MPEG-1 Video is defined in Part 2 of the MPEG-1 standard (known formally as ISO/IEC-11172-2).

enumerator MPEG2_Video¶

MPEG-2 Video is defined in Part 2 of the MPEG-2 standard (known formally as ISO/IEC 13818-2 and as ITU-T H.262).

enumerator MPEG4_Video¶

MPEG-4 Video is defined in Part 2 of the MPEG-4 standard (known formally as ISO/IEC 14496-2).

enumerator H261¶

H.261 Video is defined in the ITU-T H.261 standard.

enumerator H263¶

H.263 Video is defined in the ITU-T H.263 standard.

enumerator H264¶

H.264 Video (also known as MPEG-4 AVC / Advanced Video Codec).

Defined in Part 10 of the MPEG-4 standard (known formally as ISO/IEC 14496-10 and as ITU-T H.264).

The actual bitstream format is determined by the stream sub-type:

StreamSubType::AVC_Annex_B

H.264 Bitstream WITH start codes

H.264 bitstreams are transmitted in this format over the air, or contained in MPEG-2 program or transport streams. The H.264 bitstream is formatted as described in Annex B of ITU-T Rec. H.264. According to this specification, the bitstream consists of a sequence of NALUs (Network Abstraction Layer Units). Each NALU is prefixed with a start code equal to 0x000001 or 0x00000001.

StreamSubType::AVC1

H.264 Bitstream WITHOUT start codes

H.264 bitstreams are stored in the MP4 container in this format. Instead of start codes, each NALU (Network Abstraction Layer Units) is prefixed by a length field, which gives the length of the NALU in bytes. The size of the length field can vary, but is typically 1, 2, or 4 bytes.

enumerator AVC¶

Alias.

Same as StreamType::H264.

enumerator WMV¶

Microsoft Windows Media Video.

enumerator MJPEG¶

Motion JPEG (M-JPEG).

enumerator VC1¶

VC-1 Video is defined in the SMPTE 421M-2006 standard.

enumerator AVS¶

Advanced Video Standard (Chinese national standard).

enumerator VP8¶

VP8 is an open video codec released by Google, originally created by On2 Technologies.

VP8 is part of the WebM format.

enumerator Theora¶

Theora Video Codec.

This is an open standard video codec developed by the Xiph.Org Foundation.

enumerator H265¶

H.265 Video (also known as MPEG-H HEVC / High Efficiency Video Codec ).

Defined in Part 2 of the MPEG-H standard (known formally as ISO/IEC 23008-2 and as ITU-T H.265).

enumerator HEVC¶

Alias.

Same as StreamType::H265.

enumerator VP9¶

VP9 is an open video codec released by Google as a successor to VP8.

VP9 is part of the WebM format. @verison 3.3

enumerator AV1¶

AV1 is an open, royalty-free video coding format designed for video transmissions over the Internet.

@verison 3.3

enumerator AV2¶

AV2 is the successor to the AV1 video coding format.

It is being developed by the Alliance for Open Media (AOMedia). @verison 3.3

enumerator END_VIDEO¶

This constant marks the end of the elementary video streams.

It is not a valid stream type on its own.

enumerator BEGIN_CONTAINER¶

This constant marks the start of audio/video containers.

It is not a valid stream type on its own.

enumerator AVI¶

Audio Video Interleave (AVI) multimedia container format.

enumerator MP4¶

MPEG-4 multimedia container format specified in Part 14 of the MPEG-4 standard (formally ISO/IEC 14496-14:2003).

enumerator ASF¶

Advanced Systems Format (formerly Advanced Streaming Format, Active Streaming Format) (ASF).

enumerator MPEG_PS¶

MPEG program stream.

enumerator MPEG_TS¶

MPEG transport stream.

enumerator MPEG_PES¶

MPEG Packetized Elementary Stream (PES).

enumerator WAVE¶

Waveform Audio file format (WAV, WAVE).

enumerator FLV¶

Adobe Flash Video container format (FLV).

Not to be confused with F4V which is a newer Flash Video container format based on ISO/IEC 14496-12 (MPEG-4 Part 12).

enumerator OGG¶

Open standard container format developed by the Xiph.Org Foundation.

enumerator WebM¶

Open standard container format based on a profile of Matroska.

enumerator IVF¶

Duck Keyframe / Interframe Video Format.

This is a simple (video only) container format that transports raw VP8, VP9, AV1, and AV2 video.

Version

3.3

enumerator END_CONTAINER¶

This constant marks the end of audio/video containers.

It is not a valid stream type on its own.

enumerator BEGIN_IMAGE¶

This constant marks the start of image types.

It is not an image type on its own.

enumerator BMP¶

BMP image.

enumerator PNG¶

PNG image.

enumerator JPEG¶

JPEG image.

enumerator TIFF¶

TIFF image.

enumerator GIF¶

GIF image.

enumerator END_IMAGE¶

This constant marks the end of image types.

It is not an image type on its own.

enumerator BEGIN_DATA¶

This constant marks the start of various data types.

enumerator Teletext¶

Teletext data.

enumerator MPEG_PSI_PACKETS¶

MPEG Transport Stream Program Specific Information.

enumerator MPEG_TS_PACKETS¶

MPEG transport stream packets.

This is not a complete transport stream but rather a subset of the original transport stream.

enumerator END_DATA¶

This constant marks the end of various data types.
