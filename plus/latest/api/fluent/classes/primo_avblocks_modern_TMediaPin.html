TMediaPin¶

primo::avblocks::modern::TMediaPin

class TMediaPin : public primo::avblocks::modern::TParamsMixin<TMediaPin>¶

Fluent wrapper for primo::avblocks::MediaPin, which represents an elementary media stream.

A pin can exist for audio, video or any other kind of stream, but AVBlocks processes only audio and video streams. Pins are the inputs and outputs of a TMediaSocketT. A transcoder matches input and output pins by their connection ID (see connection()). Codec parameters are added with addParam().

Owns the raw object through a primo::ref. Not copyable, movable.

Unnamed Group

inline TMediaPin &&connection(int32_t connectionID) &&¶
inline TMediaPin &connection(int32_t connectionID) &¶

Sets the connection ID of the pin.

A transcoder matches and connects input and output pins by their connection ID. Do not confuse it with the stream ID defined for certain stream types.

Parameters:

connectionID – PinConnection::Disabled to exclude the pin, PinConnection::Auto for automatic matching, or any positive integer to match with an output pin that has the same ID.

Returns:

This object, for chaining. On a temporary the rvalue overload returns the object by rvalue reference.
