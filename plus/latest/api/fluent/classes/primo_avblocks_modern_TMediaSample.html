TMediaSample¶

primo::avblocks::modern::TMediaSample

class TMediaSample¶

Fluent wrapper for primo::codecs::MediaSample, one or more samples of audio or video data.

Holds compressed or uncompressed data in a TMediaBuffer together with timing and stream information. Owns the raw object through a primo::ref. Not copyable, movable.

Unnamed Group

TMediaSample(TMediaSample&&) = default¶
TMediaSample &operator=(TMediaSample&&) = default¶

Move construction/assignment transfers ownership of the underlying object. The moved-from object no longer wraps anything.
