TMediaSocketT¶

primo::avblocks::modern::TMediaSocketT

template<typename CharT = char>
class TMediaSocketT : public primo::avblocks::modern::TParamsMixin<TMediaSocketT<char>>¶

Fluent wrapper for primo::avblocks::MediaSocket, an input or output point of a transcoder.

A socket describes either a container (WAV, AVI, MP4, etc.) with one or more streams, or a single elementary stream (MP3, M2V, etc.). Its pins (see pins()) describe the contained streams. Socket parameters, such as muxer options, are added with addParam(). The setters can be chained and return the object by rvalue reference on a temporary, so a whole socket can be built in one expression: 

TMediaSocket("out.mp4").addPin(TMediaPin().streamInfo(video));

Template Parameters:

CharT – char for UTF-8 std::string paths, wchar_t for std::wstring paths. Use the aliases TMediaSocket and TMediaSocketW. Owns the raw object through a primo::ref. Not copyable, movable.

Unnamed Group

template<typename Fn>
inline TMediaSocketT &&pinRef(int32_t index, Fn &&fn) &&¶
template<typename Fn>
inline TMediaSocketT &pinRef(int32_t index, Fn &&fn) &¶

Gives you a reference to the pin at index, so you can do something with it (read it or change it) without leaving a fluent chain.

fn is called once, immediately, with a TMediaPin& that refers to the pin inside this socket (it is not a copy), so changes made through it apply to the socket. The socket itself is returned, so chaining continues.

Use this instead of pins(index): that returns the pin and ends the chain, so the socket is no longer available to pass on, e.g. to TTranscoder::addOutput(). 

TTranscoder()
    .addInput(TMediaSocket(mediaInfo))
    .addOutput(
TMediaSocket(mediaInfo)
            .file("out.mp4")
            .pinRef(0, [](TMediaPin& pin) {
                pin.videoStreamInfo().frameRate(30.0);
            }))
    .open().run().close();

Parameters:

  • index – Zero-based index of the pin.

  • fn – Callable taking TMediaPin&.

inline TMediaSocketT &&videoInfoRef(int32_t index, Fn &&fn) &&¶
template<typename Fn>
inline TMediaSocketT &videoInfoRef(int32_t index, Fn &&fn) &¶

Gives you a reference to the video stream info of the pin at index, so you can do something with it (read it or change it) without leaving a fluent chain. Shorter than pinRef() when only the stream info is needed.

fn is called once, immediately, with a TVideoStreamInfo& that refers to the stream info inside the pin (it is not a copy), so changes made through it apply to the socket. The socket is returned, so chaining continues. The pin must be a video pin. 

TMediaSocket(mediaInfo).file("out.mp4")
    .videoInfoRef(0, [](TVideoStreamInfo& video) { video.frameRate(30.0); })

Creates a socket from a TMediaInfo, wrapping Library::createMediaSocket(MediaInfo*).

The created socket contains the file path and pins from the media info, ready to be added as a transcoder input. Member template so the body is instantiation-checked, allowing TMediaInfo to be defined after TMediaSocketT without a circular dependency.
