TStreamInfo¶

primo::avblocks::modern::TStreamInfo

template<typename Derived, typename RawT>
class TStreamInfo¶

CRTP base for TAudioStreamInfo, TVideoStreamInfo, and TDataStreamInfo.

Holds the primo::ref<RawT> and exposes all properties defined on the raw primo::codecs::StreamInfo interface, with fluent setters that return Derived& (on lvalues) or Derived&& (on temporaries) so chaining works naturally on the concrete subclass. The rvalue overloads let a chained temporary be returned or moved, e.g. return TVideoStreamInfo().frameWidth(352).frameHeight(288);
