TTranscoderT¶

primo::avblocks::modern::TTranscoderT

template<typename CharT = char>
class TTranscoderT¶

Fluent wrapper for primo::avblocks::Transcoder, which encodes, decodes and transforms audio and video.

Add input and output sockets, then either run the whole job with transcode() (file to file), or drive it step by step: open(), run() or push() / pull() / flush(), then close(). Failures are reported with TAVBlocksException; the try* variants return false instead. Progress and status are received through lambdas (see onProgress()). 

TTranscoder()
    .allowDemoMode(true)
    .addInput(TMediaSocket(mediaInfo))
    .addOutput(TMediaSocket("out.mp4"))
    .transcode();

Template Parameters:

CharT – char or wchar_t, matching the sockets used. Use the aliases TTranscoder and TTranscoderW. Owns the raw object through a primo::ref. Not copyable, movable.

inline bool push(int32_t inputIndex, TMediaSample &sample)¶

Pushes input data to the transcoder.

The sample is used only within this call and is not retained. The transcoder may consume only part of it: on return the buffer’s data offset and size show what is left, which matters when more data is appended for the next push.

Parameters:

  • inputIndex – Index of the input socket the data is for.

  • sample – The input data.

Returns:

true on success.

inline bool pushEos(int32_t inputIndex)¶

Signals end-of-stream on the input socket at inputIndex.

Equivalent to pushing a null (empty) sample.

inline void close()¶

Closes the transcoder. When closed it neither accepts nor delivers data. The inputs and outputs are not modified.

inline void transcode()¶

Opens, runs and closes the transcoder (file to file mode): the whole open().run().close() sequence in one call.

The transcoder is closed even if run() throws; TAVBlocksException is thrown if it cannot be opened or fails to run. 

TTranscoder().allowDemoMode(true).addInput(in).addOutput(out).transcode();

inline bool flush()¶

Flushes the data buffered in the transcoder to the output and marks the end of the stream for all inputs.

Push mode only. Do not push data after flushing.

Returns:

true on success.

inline TErrorInfo error() const¶

Returns the error information for the last operation.

inline primo::avblocks::Transcoder *get() const¶

Returns the raw underlying pointer. For interop with the core API only.
