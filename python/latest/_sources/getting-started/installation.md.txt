# Installation

AVBlocks Python SDK is not distributed via PyPI. Install it directly from the GitHub repository.

## Prerequisites

- Python 3.9 or higher
- pip or uv package manager

## Install with pip

```bash
pip install git+https://github.com/avblocks/avblocks-py.git@3.4.0.1
```

## Install with uv

From within your project directory:

```bash
uv add git+https://github.com/avblocks/avblocks-py.git --tag 3.4.0.1
```

This adds `avblocks` as a dependency in your `pyproject.toml`.
